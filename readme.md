# 图书管理系统
> 这是一个使用Java Swing写的UI
> 
## 功能
- **管理员：**三个管理界面
  - 图书数据管理（含分类栏）
  - 读者信息管理
  - 还书管理（含读者栏）

- **读者：**两个界面
  - 借书（含分类栏）
  - 还书

## 项目结构

```
/
├── src/              
    ├── data/        # 数据实体
    │   └── ...
    ├── dbframe/     # 数据库框架
    │   └── ...
    ├── gui/
    │   ├── util/       # 面板切换、输入框切换工具
    │       └── ...
    │   ├── wrapper/    # 封装的面板
    │   ├── Login.java  # 登录窗口
    │   ├── MainFrame   # 管理员专用窗口
    │   └── ReaderFrame # 读者专用窗口
    └──service/   # 数据库业务逻辑
        └── ...
```
